AUTOMATIC PRICE SYNC:
CATALOG_URL=https://buildspare.site/packages
CATALOG_SYNC_SECONDS=900

The bot checks the supplier's public package catalog at startup and every 15 minutes (900 seconds).
If the page layout changes or prices cannot be reliably parsed, the bot keeps the last known prices and logs a warning. The supplier's published API documentation does not list an official catalog API endpoint, so this uses the public Packages page and is dependent on that page's HTML layout. Public catalog prices may differ from any account-specific API charge; verify against your reseller wallet before live sales.

ADMIN-ONLY PRICE COMMANDS (supplier costs are not shown to customers):
/rates — show catalog/API cost, customer price, and auto/manual source
/syncprices — manually refresh prices from the public catalog
/setrate TAG_LINE PRICE — set an admin-only manual cost override, e.g. /setrate 25 20.50
/autoprice TAG_LINE — remove manual override and return to automatic catalog prices, e.g. /autoprice 25

Manual overrides persist until /autoprice TAG_LINE is used. Automatic sync updates only non-manual package prices. Customer-facing screens show only the final selling price (including markup), never the supplier cost.

PACKAGE CATALOG:
The bot includes the 16 BD SERVER packages transcribed from the catalog provided by the owner. If automatic sync fails, the built-in prices are used until a successful sync occurs. PACKAGES_JSON is optional and can override the package names/tags/base costs, but automatic catalog sync matches the 16 built-in BD tags.
